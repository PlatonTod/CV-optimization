# Dimax HR v2 — відбір кандидатів (Streamlit + Gemini)

Три вкладки, как на тестовом сайте, но приложение работает на ключе Gemini и принимает выгрузки Betterteam:

1. **Вакансії** — HR заполняет критерии (должность, языки с уровнем, инструменты, локация; опыт, образование, нюансы),
   ИИ генерирует промпт оценки, его можно отредактировать и сохранить. При первом запуске уже есть
   MEA Sales Manager и Country Manager (Dubai) с готовыми промптами.
2. **Кандидати та оцінка** — загрузка одного или нескольких CSV из Betterteam (резюме скачиваются по ссылкам из CSV),
   при необходимости — файлы резюме или ZIP (если ссылка не открывается или кандидата нет в CSV).
   Оценка сразу по нескольким вакансиям; повторно оцениваются только новые кандидаты и те, чей промпт изменился.
3. **Результати** — таблица по выбранной вакансии (балл, баллы по другим вакансиям, языки, локация, опыт, образование),
   фильтры, поиск, клик по строке — что совпало и чего не хватает; Excel с листом на каждую вакансию.

## Стоимость (Gemini Flash, платный ключ)
~1100 резюме × 2 вакансии ≈ $1–3. «Економний фільтр» (по умолчанию включён) не отправляет в ИИ резюме без признаков
UA/СНД/Балтии — только для вакансий, где украинский/русский обязателен. Перед запуском приложение показывает оценку
числа запросов и стоимости, после — фактические токены.

## Деплой на Streamlit Community Cloud (бесплатно)

1. GitHub → **New repository** → *Private* → загрузите все файлы этой папки (включая `.streamlit/config.toml`;
   `.gitignore` не даст закоммитить CSV, Excel и данные кандидатов).
2. https://share.streamlit.io → вход через GitHub → **Create app** → репозиторий, ветка `main`, файл `app.py`.
3. **Advanced settings**: Python **3.12**; в **Secrets** вставьте:
   ```toml
   APP_PASSWORD = "придумайте пароль для HR"
   LLM_API_KEY  = "ключ Gemini из aistudio.google.com (проект с оплатой)"
   ```
4. **Deploy**. Через 3–5 минут будет ссылка вида `https://dimax-hr.streamlit.app` — её и пароль отправьте HR.
5. В настройках приложения (**Settings → Sharing**) оставьте доступ по ссылке: вход и так защищён паролем.

**Важно про облако:** Streamlit Cloud стирает сохранённые файлы при перезапуске и «засыпании» приложения
(несколько дней без визитов). Поэтому после работы скачивайте **«💾 Резервна копія всіх даних»** (вкладка «Кандидати»)
и восстанавливайте её там же. Вакансии отдельно — «Резервна копія вакансій» на вкладке «Вакансії».
Резюме кандидатов при этом обрабатываются на серверах Streamlit (США) и Google — проверьте, что это допустимо для компании.

## Другие варианты запуска
- **Свой компьютер:** Python 3.11+ → двойной клик `run_app.bat`. Данные хранятся в папке `hr_data/` и не пропадают.
- **Свой сервер (Docker):**
  ```bash
  docker build -t dimax-hr .
  docker run -d -p 8501:8501 -v dimax_hr_data:/data -e APP_PASSWORD=... -e LLM_API_KEY=... dimax-hr
  ```

## Если что-то не так
- «посилання не відкривається (403)» — ссылки Betterteam на файлы со временем истекают: сделайте свежую выгрузку CSV
  или загрузите файлы резюме/ZIP — они привяжутся к кандидатам по имени файла из ссылки или по имени кандидата.
- «Ліміт запитів вичерпано» — в бесплатном режиме кончилась дневная квота Google (обновляется в 10:00 по Киеву);
  нажмите «Оцінити» на следующий день, продолжит с места остановки.
